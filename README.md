# Product-sales-analysis
This repository contains the solution for Task 7 of the Data Analyst Internship, adapted to use MySQL instead of SQLite. The script connects to a MySQL database, executes SQL queries to calculate total quantity sold and revenue per product, and displays the results using print statements and a simple bar chart created with matplotlib. Key steps include establishing a MySQL connection, running GROUP BY queries, loading data into a pandas DataFrame, and visualizing revenue by product. This project demonstrates foundational skills in SQL, Python data manipulation, and basic plotting, while also showcasing flexibility in working with different database systems. For details, review the Jupyter Notebook or Python script included.
